# DungeonArchitect v0.3 + DA-1.01

2D-редактор подземелий на **Godot 4.7.2**, GDScript. Без сторонних библиотек.

## Как запустить

1. Распакуй ZIP в любую папку.
2. Открой Godot → **Import** → выбери `project.godot` в распакованной папке.
3. Открой проект, дождись импорта PNG-файлов.
4. Нажми **F5** (Run Project). Откроется отдельное окно DungeonArchitect.

### Редактор

- Чистая карта 16×16 клеток при старте проекта, без демо-подземелья.
- Инструменты: рука (безопасная навигация), пол, стена, дверь, сундук, монстр, ключ, зелье, лестница вниз, триггер, старт игрока и ластик.
- Палитра инструментов теперь отображается **иконками**, а не словами.
- **Новая карта**: пресеты 16×16, 32×32, 48×48, 64×64 или произвольная ширина и высота в диапазоне 1…256.
- Карта 1×1 создаётся без автоматической граничной стены, чтобы можно было поставить героя.
- Клетки имеют два слоя: `terrain` и `entities`. В одной клетке могут находиться несколько разных сущностей.
- В режиме кисти: рисование удержанием ЛКМ или одним пальцем, стирание ПКМ. Масштаб колесом и панорамирование средней кнопкой мыши (или Space+ЛКМ) на ПК.
- Показ и скрытие сетки, кнопка «Вписать», координаты курсора.
- Сохранение в `user://maps/<id>.json` и загрузка из встроенной библиотеки.
- Импорт/экспорт самостоятельных JSON-файлов через системный файловый диалог.
- **Рука** (выбрана по умолчанию): один палец или ЛКМ двигает карту, два пальца двигают и масштабируют. Карта не меняется ни при каких жестах в этом режиме. В инструментах рисования палец рисует; многопальцевое касание блокирует кисть до полного отпускания пальцев.

### Тестовый игровой режим

- Кнопка **«Играть»** запускает тест текущей карты.
- **Экранная крестовина** внизу слева: четыре стрелки, одно касание = один ход, работает на планшете и мышью.
- Стрелки клавиатуры перехватываются игровым режимом до навигации интерфейса.
- Для старта теста на карте должна быть поставлена **точка старта героя**.
- Герой перемещается **стрелками** или **WASD**.
- Один шаг = один ход.
- Стены блокируют движение.
- Включён **туман войны**: изначально карта скрыта, герой открывает ближайшие клетки по мере движения.
- Кнопка **«В редактор»** или клавиша **Esc** возвращают обратно.
- Игровой режим **не изменяет саму карту** — он работает поверх неё как отдельная `GameSession`.

## Где лежат внутренние сохранения

Сохранённые внутри приложения карты лежат в папке пользовательских данных Godot (`user://maps`).
В редакторе путь к `user://` можно открыть через меню **Project → Open User Data Folder**.
На Windows обычно это:

```text
%APPDATA%\Godot\app_userdata\DungeonArchitect\maps
```

## Продолжение работы и инвентарь (DA-2.04)

- После загрузки или сохранения карты редактор запоминает её ID в локальном `user://editor_state.cfg`. При новом запуске автоматически открывает последнюю сохранённую карту. Несохранённые правки не восстанавливаются.
- В тестовом режиме кнопка **Инвентарь** или клавиша **I** открывает список найденных предметов, их свойства, золото и экипировку. Кнопка закрытия, **I** и **Esc** возвращают к исследованию; пока окно открыто, перемещение героя заблокировано. Использование предметов и ручная смена экипировки появятся позже.
